# Рабочее место Dialer

Маршрут `/app/dialer` использует существующую проектную очередь, 15-минутный lease клиента,
heartbeat и каноническую state machine звонка. Интерфейс не зависит от конкретного
телефонного провайдера: все команды проходят через FastAPI и `TelephonyService`.

## Восстановление рабочего места

- `GET /api/v1/dialer/current` восстанавливает назначение и продлевает lease.
- `GET /api/v1/calls/active` возвращает незавершённый звонок либо терминальный звонок без результата.
- `GET /api/v1/dialer/flow/{call_id}` создаёт или восстанавливает выполнение зафиксированной
  опубликованной версии сценария.
- `GET /api/v1/dialer/history/details` возвращает историю клиента со snapshot результата,
  комментарием, оператором, transcript и summary.
- `GET /api/v1/calls/{call_id}/state` является источником `allowed_actions` для кнопок линии.

При закрытии страницы без звонка frontend отправляет release через keepalive. Активный или
терминальный звонок без результата сохраняет assignment, чтобы оператор продолжил работу после
перезагрузки.

## Runtime сценария

`CallFlowExecution` связывает один Call с одной опубликованной `CallFlowVersion`. Каждый переход
проверяется backend по текущему node ID и `state_version`. `CallFlowExecutionStep` хранит
неизменяемый snapshot показанного текста, ответа, введённого значения и перехода.

Action-узлы выполняются только после подтверждения оператора. Поддержаны обновление поля клиента,
создание задачи, создание callback и Mock transfer. `Idempotency-Key` исключает повторное
выполнение действия. Preview редактора не использует runtime service и не создаёт побочных данных.

Возврат назад меняет текущий узел, но намеренно не отменяет уже подтверждённые действия. Этот факт
сохраняется в истории шага как `history_not_reverted`.

Источник текущего назначения (`callback`, `retry` или `new`) сохраняется вместе с lease и не
меняется после старта звонка, heartbeat либо перезагрузки страницы.

## Сохранить и следующий

`POST /api/v1/dialer/complete-and-next` принимает Call, customer, lock token, ожидаемые версии,
проектный результат и `Idempotency-Key`. В одной транзакции операция:

1. проверяет tenant, project, operator, Call и lease;
2. сохраняет outcome и исторический snapshot результата;
3. применяет callback/task/do-not-call и статус клиента;
4. завершает выполнение сценария и исходную callback-задачу;
5. освобождает lease;
6. получает следующую задачу или клиента через `FOR UPDATE SKIP LOCKED`;
7. сохраняет точный response для безопасного replay.

Если очередь пуста, результат остаётся сохранённым и `next_assignment` равен `null`.

## Горячие клавиши

- `Alt+C` — начать звонок;
- `Alt+H` — завершить или отменить звонок;
- `Alt+P` — hold/resume;
- `Alt+R` — перейти к результату;
- `Ctrl+Enter` — сохранить;
- `Ctrl+Shift+Enter` — сохранить и получить следующего клиента.

Shortcuts отключены внутри input, textarea, select, button, contenteditable и modal.

## Live-блокеры

Микрофон и громкость показываются недоступными до подключения WebRTC/browser media. Настоящие SIP,
Asterisk и OpenAI Realtime этим этапом не подключены. Текущий flow полностью проверяется через
детерминированный `MockTelephonyProvider`.
